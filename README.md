# חוקה ברוח מסמך העקרונות — טיוטה לדיון

טיוטת חוקה למדינת ישראל שנוסחה מתוך המצעים, העקרונות וההצהרות הפומביות של **ביחד, ישראל ביתנו, הדמוקרטים וישר!**, בהתאם למסמך העקרונות של ראשי המפלגות מיום 26.9.2026.

## המסמכים

| מסמך | מקור (markdown) | אתר | PDF |
|---|---|---|---|
| החוקה (100 סעיפים + נספח מקורות) | `docs/constitution.md` | `constitution.html` | `pdf/חוקה-טיוטה.pdf` |
| תקציר | `docs/summary.md` | `summary.html` | `pdf/תקציר-החוקה.pdf` |
| מחלוקות וחלופות | `docs/disputes.md` | `disputes.html` | `pdf/מחלוקות-וחלופות.pdf` |
| מכתב הסבר | `docs/letter.md` | `letter.html` | `pdf/מכתב-הסבר.pdf` |

קובצי ה-markdown ב-`docs/` הם מקור האמת. עמודי ה-HTML וה-PDF נבנים מהם.

## עריכה ובנייה מחדש

```bash
pip install markdown playwright && playwright install chromium
python3 build.py            # docs/*.md  →  *.html
python3 tools/make_pdf.py   # *.html     →  pdf/*.pdf
```

## הצעות לתיקון

פותחים Issue או Pull Request על הקובץ המתאים ב-`docs/`. כל שינוי בנוסח החוקה צריך להפנות למקור מפלגתי (מסמך, דובר, תאריך) — כפי שעשוי בנספח המקורות.

## מה זה לא

לא נוסח סופי ולא מסמך מטעם המפלגות. חלק מהעמדות לקוח מתשובות לשאלוני עיתונים ומראיונות, לא מהתחייבויות מחייבות; כל ציטוט מובא עם הדובר, המקור והתאריך.
