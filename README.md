# קווי היסוד לממשלה הבאה — תוצרי קבוצה ב', ברוח מסמך העקרונות. טיוטות לדיון

> **טיוטה עצמאית — אין לה קשר למפלגות.** המאגר והאתר אינם מטעם ביחד, ישראל ביתנו, הדמוקרטים או ישר!, והטקסטים בהם לא אושרו על ידן.

קווי היסוד לממשלה, החוקה, שלושה נוסחים משפטיים ותוכנית 100 הימים — טיוטה עצמאית למשימות שמסמך העקרונות של ראשי המפלגות מיום 26.9.2026 הטיל על קבוצה ב'. כל התוכן נוסח מתוך המצעים, העקרונות וההצהרות הפומביות של **ביחד, ישראל ביתנו, הדמוקרטים וישר!** בלבד, ולכל סעיף יש מקור.

אתר: https://yahalevy.github.io/tikkun-tikva-group-b/

## המסמכים

עמוד הבית הוא תקציר התוצרים, לפי סדר המנדט: קווי היסוד כמסגרת, ואחריהם חמשת פרקי הליבה שלהם — חוקה, ועדת חקירה, שוויון בנטל, הגבלת כהונה ו-100 הימים — כל אחד בעמוד משלו. מסמך המחלוקות מרכז את המחלוקות שבכל התוצרים, ומכתב ההסבר ("על המסמכים") מסביר איך נוסחו.

קובצי ה-markdown ב-`docs/` הם מקור האמת. עמודי ה-HTML (ובהם `index.html`) וה-PDF נבנים מהם. הגופנים: Noto Sans Hebrew ו-Frank Ruhl Libre, שניהם ברישיון SIL OFL (`assets/fonts/`).

## עריכה ובנייה מחדש

```bash
pip install markdown playwright && playwright install chromium
python3 build.py            # docs/*.md  →  *.html
python3 tools/make_pdf.py   # *.html     →  pdf/*.pdf
```

## מה זה לא

לא מסמך מטעם המפלגות ולא נוסח סופי. אין למאגר קשר לביחד, לישראל ביתנו, לדמוקרטים או לישר!, והוא לא אושר על ידן. ההכרעות שמסומנות "הוכרע במטה" הן הכרעות של כותבי הטיוטה, וכולן טעונות אישור ראשי המפלגות. חלק מהעמדות לקוח מתשובות לשאלוני עיתונים ומראיונות, לא מהתחייבויות מחייבות; כל ציטוט מובא עם הדובר, המקור והתאריך.
