# החוקה ותוצרי קבוצה ב' — ברוח מסמך העקרונות, טיוטות לדיון

החוקה, קווי היסוד לממשלה, שלושה נוסחים משפטיים ותוכנית 100 הימים — עבודת המטה של קבוצה ב' לפי מסמך העקרונות של ראשי המפלגות מיום 26.9.2026. כל התוכן נוסח מתוך המצעים, העקרונות וההצהרות הפומביות של **ביחד, ישראל ביתנו, הדמוקרטים וישר!** בלבד, ולכל סעיף יש מקור.

אתר: https://yahalevy.github.io/israel-constitution-tikkun-and-tikva-parties/

## המסמכים

סדר הקריאה באתר: החוקה ← קווי היסוד ← שלושת החוקים ← 100 הימים. מכתב ההסבר והתקציר מכסים את כל התוצרים, ומסמך המחלוקות מרכז את המחלוקות שבכולם.

| מסמך | מקור (markdown) | אתר | PDF |
|---|---|---|---|
| מכתב הסבר | `docs/letter.md` | `letter.html` | `pdf/מכתב-הסבר.pdf` |
| תקציר | `docs/summary.md` | `summary.html` | `pdf/תקציר-החוקה.pdf` |
| החוקה (100 סעיפים + נספח מקורות) | `docs/constitution.md` | `constitution.html` | `pdf/חוקה-טיוטה.pdf` |
| קווי היסוד לממשלה (68 סעיפים) | `docs/guidelines.md` | `guidelines.html` | `pdf/קווי-היסוד-לממשלה.pdf` |
| הצעת חוק-יסוד: הגבלת כהונת ראש הממשלה | `docs/term-limits.md` | `term-limits.html` | `pdf/הצעת-חוק-יסוד-הגבלת-כהונה.pdf` |
| ועדת חקירה ממלכתית — טיוטת החלטת ממשלה | `docs/inquiry.md` | `inquiry.html` | `pdf/ועדת-חקירה-ממלכתית.pdf` |
| הצעת חוק השוויון בנטל | `docs/equal-burden.md` | `equal-burden.html` | `pdf/הצעת-חוק-השוויון-בנטל.pdf` |
| הכרעה — היקף הדחייה (לחוק השוויון בנטל) | `docs/deferral-decision.md` | `deferral-decision.html` | `pdf/הכרעה-היקף-הדחייה.pdf` |
| תוכנית 100 הימים | `docs/100-days.md` | `100-days.html` | `pdf/תוכנית-100-הימים.pdf` |
| מחלוקות וחלופות | `docs/disputes.md` | `disputes.html` | `pdf/מחלוקות-וחלופות.pdf` |

קובצי ה-markdown ב-`docs/` הם מקור האמת. עמודי ה-HTML (ובהם `index.html` ו-`laws.html`) וה-PDF נבנים מהם.

## עריכה ובנייה מחדש

```bash
pip install markdown playwright && playwright install chromium
python3 build.py            # docs/*.md  →  *.html
python3 tools/make_pdf.py   # *.html     →  pdf/*.pdf
```

## מה זה לא

לא נוסח סופי ולא מסמך מטעם המפלגות. ההכרעות שהתקבלו במטה מסומנות, וכולן טעונות אישור ראשי המפלגות. חלק מהעמדות לקוח מתשובות לשאלוני עיתונים ומראיונות, לא מהתחייבויות מחייבות; כל ציטוט מובא עם הדובר, המקור והתאריך.
